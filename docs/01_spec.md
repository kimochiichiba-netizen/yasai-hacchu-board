# やさい発注ボード 仕様書

- 作成日: 2026-05-30
- 発注元: 株式会社気持ち市場（青果卸売業）
- 目的: 取引先からの手書き仕入れ表を、社長が目視・文字起こしする手間をゼロにする。発注受付から納品書・請求書の発行までを一気通貫で行う。

## 1. 概要

手書きの「野菜仕入れ表」をそのままWeb画面化する。取引先が画面で「品目・数量・サイズ／品種・希望金額」を入力／選択して送信 → 社長の管理画面に届く → 社長は単価を確定するだけで、納品書と請求書がPDFで発行できる。あわせて「今が買い時／これから高くなる」野菜を旬カレンダーから自動でおすすめ表示する。

## 2. 利用者と画面

| 画面 | 利用者 | 役割 |
|---|---|---|
| ① 発注画面 (`index.html`) | 取引先 | 仕入れ表そっくりの一覧から数量・サイズ・希望金額を入力して送信。上部に旬のおすすめ表示。スマホ対応。 |
| ② 管理画面 (`admin.html`) | 社長 | 届いた注文の一覧・詳細。単価を確定し、納品書PDF・請求書PDFを発行。商品マスタ・旬・価格傾向の調整。パスワード保護。 |

## 3. 主要フロー

1. 取引先が発注画面で数量等を入力 → 送信
2. 注文がデータストアに保存される（社長側に届く）
3. 社長が管理画面で注文を開き、各品目の確定単価を入力（取引先の希望金額を参考に）
4. 「納品書PDF」「請求書PDF」を発行（ブラウザ印刷でPDF化）

## 4. おすすめ（安くなる／高くなる）ロジック

- 各品目に「旬（出回り月）」をプリセット。
- 当月の判定:
  - 当月が旬 → 「📉 今が買い時（旬）」
  - 翌月から旬入り → 「📉 これから安くなる」
  - 当月で旬終わり（翌月は旬でない） → 「📈 これから高くなる」
  - それ以外（端境期） → 高め
- 社長が品目ごとに手動で「安い／高い／自動」を上書き可能。

## 5. 土台（技術）

- フロント: 静的Webアプリ（HTML/CSS/バニラJS）。Netlify か GitHub Pages で無料公開。インストール不要、URL共有で利用。
- データストア: **二層構成**
  - 既定: ブラウザの localStorage（鍵登録なしで即動作。1台内で完結＝デモ・社内検証用）
  - 本番: Supabase 無料枠（URL+anon key を設定すると複数端末で共有。取引先↔社長でリアルタイム連携）
  - `assets/store.js` が設定の有無を見て自動切替（前ERPの MOCK_MODE 思想を踏襲）
- PDF: ブラウザ印刷で納品書・請求書をPDF化（追加費用ゼロ）。
- 消費税: 食品のため軽減税率 **8%** で計算。

## 6. データモデル

- products: 品目（id, 名称, カテゴリ, 単位候補, 品種/サイズ候補, 旬の月, 標準単価）
- partners: 取引先（id, 名称, 連絡先）
- orders: 注文（id, 取引先, 注文日, 納品予定日, ステータス）
- order_items: 注文明細（品目, 数量, サイズ/品種, 希望金額, 確定単価）
- price_overrides: 価格傾向の手動上書き（品目, 傾向）

ステータス: `received`（受付）→ `priced`（単価確定）→ `done`（発行済）

## 7. 今回やらないこと（YAGNI）

- Freee会計連携、LINE通知、在庫管理（既存 kimochi-erp の領域。後から追加可能）。

## 8. 安全・運用（社長操作が必要な箇所）

- Supabase 無料アカウント登録・URL/anon key の取得は社長ご本人が実施（鍵の代理入力はしない）。
- Netlify / GitHub Pages への公開も社長ご本人が実施（外部公開のため）。
- 鍵が無くても localStorage モードで全機能が動作するため、検証はすぐ可能。
